# Adversarial review of IMPLEMENTATION.md — 2026-09-12

**Status:** all 32 findings folded into `REQUIREMENTS.md` and `IMPLEMENTATION.md` on 2026-09-12, except the disputed premise checks in item 19 (left to the prompt) and the host question in item 25 (resolved: the rule means private hosts; `CLAUDE.md` reworded).

Four independent Opus reviewers (generality, concurrency, model/measurement, tests/sequencing), findings merged and deduplicated, ranked by what would cost the most if built as written. Severity: **S1** breaks the first live game or invalidates the measurement; **S2** wrong by construction, cheap to fix now, expensive later; **S3** should fix before M6. Each item names the doc section to change. Items marked *disputed* are where the reviewers overreach or the fix is deferred.

## S1 — would break M4 or make its numbers meaningless

1. **`max_tokens` 1024 truncates the tool call under adaptive thinking.** Thinking tokens count against the cap; a firefight packet burns it before `orders` closes, `stop_reason: max_tokens`, partial `tool_use` input, recorded as a vague skip. Fix: `max_tokens` 4096, handle `max_tokens` as `skipped:truncated` distinct from `refusal` and timeout. (IMPL M1 model.mjs; REQ M1, M4)
2. **Retry stacking blinds the pilot for up to 32 s.** SDK `maxRetries:1` retries timeouts too (2 × 8 s), then the plan adds its own retry on top. Fix: `maxRetries:0`, own retry with one total deadline (~6 s) via `AbortController`, and never resend a stale packet: re-encode, or skip if a newer trigger is dirty. (IMPL M1 model.mjs; REQ M4)
3. **The `orders` tool is not expressible under `strict`.** Eleven `args` shapes behind one object cannot satisfy `additionalProperties:false` + `required`. Fix: discriminated union, `$defs` + `anyOf`, `cmd:{const}` per variant, optionals as `type:[x,"null"]`. Count and length caps (`orderCap`, `train count`, `note` length) are not schema-enforceable; enforce in validate/send. Freeze the schema as a literal, record its sha next to the prompt sha. (REQ A8, §9 tool; IMPL M0 interfaces, M3 index.mjs)
4. **Delta is computed against the previous 500 ms snapshot, not the previous decision.** The model is told "what changed since the last packet" and sees 15% of it. Fix: two prevs, `prevSnapshot` for `derive`, `prevDecisionState` for `encode`. (IMPL M1 pilot.mjs; REQ A7)
5. **The dirty re-entry path bypasses cooldowns and recurses.** During any 3 s call, `derive` sets dirty within 500 ms, so firefights become back-to-back calls with no pacing, ~2× the call budget. Fix: dirty re-enters through `offer`, a floor of one state tick between decision starts, a `while` loop not recursion. Also: collect all triggers from one tick, resolve to at most one fire, pass the whole set to `encode`, else the firing packet omits the events that caused it and a second call fires on the same world. (REQ T4; IMPL M1 triggers.mjs, pilot.mjs)
6. **Output tokens, not packet tokens, dominate latency.** With a cached prefix, TTFT is a few hundred ms; 600–1000 output tokens (thinking + JSON) is 5–10 s. M6 tunes cached input first, which moves neither cost nor latency. Fix: reorder M6 to output length first (thinking off / effort, order cap, drop `note`), then packet size. Stream the call with `eager_input_streaming` on the tool and dispatch each cmd as its JSON closes: time-to-first-order, an M6 experiment. (REQ §1, §12; IMPL M6)
7. **n = 1 game per variable against a stochastic opponent proves nothing.** Win rate over three games takes four values. Fix: iterate on within-game proxies with many samples (reaction latency distribution, orders executed vs dropped/rejected, idle-production seconds, bank integral); reserve win rate for one ≥ 20-game confirmation of the final config. (REQ §12 X1, X3; IMPL M6)
8. **The headline metric is not comparable to the baseline and hides queue time.** Baseline 16–27 s includes the model-chosen wait; like-for-like is game 11's 8.7 s gap. And the clock starts at trigger fire, so a `danger` event arriving during a call is recorded as fast. Fix: report `event arrival → order on wire` p50/p90 as reaction time, model latency separately, decisions per game-minute; restate the baseline. (REQ §1; notes pace)
9. **Cost accounting is wrong and `--max-usd` concedes winning games.** Flat per-token table ignores cache write 1.25× and cache read 0.1×, over-charging the prefix ~10×; then a billing number loses a game. Fix: price the four usage fields per model from config, log all four; replace concede-on-budget with stop-deciding plus a decision-count cap; concede stays a separate opt-in. (REQ M6, X4; IMPL M1 model.mjs, pilot.mjs)
10. **M4 retires three risks in one live game.** First keyed connection, first real model call, first prompt: if game 12 goes badly nothing is attributable. Fix: insert **M3.5 offline rehearsal**: recorded states → `encode` → real `callModel`, `send` stubbed, ~20 real moments scored by hand for legality and sense; cents in cost. M4 then tests transport only. Also: the local hub exercises the open-hub auth branch, live uses the keyed branch and rejoin-by-account, so M4 step 1 is an explicit checklist (keyed upgrade, forced terminate, rejoin, round trip), not "play a game". (IMPL M2 tests, M4)

## S2 — wrong by construction, fix while it is free

11. **The core cannot express "may I act now" or "act by this deadline".** A turn-based or move-timer game burns heartbeat calls during the opponent's turn and misses its own deadline. Fix: `canAct(state)` and `deadline(state) → {atMs, cls}|null` on the contract; the trigger engine suppresses on `!canAct` and schedules a forced decision at `deadline − margin`. (REQ §4, T3, T4)
12. **The urgency vocabulary is an RTS taxonomy hardcoded in core.** `contact` = enemy sighted, `idle` = production idle; a card game's only two events both land in `info`, which ranks last. Fix: `meta.classes: string[]` ordered highest first, declared by the adapter; core treats names as opaque for ranking, cooldowns and stats. Ashfall's list moves into its adapter. Resolve the contradiction where REQ A5/A6 carry `urgency` but the type block does not: drop it, or make it `urgency?:number` that overrides class index. (REQ T1, A5, A6; IMPL types.mjs)
13. **`Header`, `done` and the tool name encode a two-sided RTS.** Four fixed phases, one elapsed clock, `side`, `won:boolean`, tool named `orders` in core. Chess has two countdown clocks and draws; a four-player game has a seat and a placement. Fix: `{lifecycle:'pregame'|'active'|'ended', phaseNative, clocks?, gameId, seat}`, `done({outcome:{won?, draw?, rank?}, duration?, why})`, `gt` optional, `meta.toolName`/`toolDescription` from the adapter, `meta.actionMode:'batch'|'single'` so `orderCap:1` shapes the schema and the metric. (REQ A3–A5, A8, R1, §1)
14. **Generic work is pushed into every adapter.** Id-set diffing, rank-and-collapse by key, edge detection for derived triggers. Adapter two copies Ashfall's coder. Fix: `src/core/digest.mjs` with `diffById` and `rankAndCollapse`; `derive` becomes a pure predicate over current state and the core owns once-per-crossing re-arm; spatial clustering in `src/lib/`, not core. (REQ A6, A7, §9; IMPL M3 coder.mjs, events.mjs)
15. **Snapshot ownership and one-seat-per-process are unstated.** Polling and diff transports have no home; a poll interval becomes a second invisible cadence. Fix: the adapter must emit a materialized snapshot and owns polling/diff merge; expose its refresh interval in `meta` so the heartbeat can align; `--record-state all|on-decision|sampled`; adapter module exports `createAdapter(env, opts)` so two seats can share a process; drop `meta.limits` (adapter-internal). (REQ A1, A5, A10, R1)
16. **The mock adapter is Ashfall-shaped and underspecified.** Hp, production, scripted waves at 4× speed tests nothing about generality, and M1's tests ask it for disconnect, cmd rejection, `queued → running`, and game-over mid-call, which the paragraph never promises. Fix: specify it as data: a `timeline` of `[tMs, kind, payload]` plus `faults` (`disconnect`, `rejectCmd`, `doneMidCall`), injected clock, `send` records rather than drives the world; make it turn-based, deadline-driven, single-action, draw-capable and clockless so items 11–13 fail loudly in M1. Pass the stub model through the injection point, not a magic `--model stub`. (IMPL M1 mock adapter, tests)
17. **Reconnect keeps deciding into a dead socket and loses edge memory.** Up to ~9 s of heartbeat decisions on a stale state, all cmds `disconnected`; after rejoin, `derive` keys from before the drop suppress a still-burning building. Fix: suspend the trigger engine on `disconnect`, clear derive memory and `prev` on `reconnect`, force one decision on the first fresh state. (REQ A11; IMPL M2 ctl.mjs)
18. **Order cap, fan-out and the bucket are placed inconsistently.** Cap-before-fan-out lets 15 × `train{count:5}` become 75 frames; clamping `count` inside `send` produces no `dropped` record so the model re-issues it forever; the bucket covers `cmd` only while the limit covers every frame (reconnect handshake, `games`, `leave`). Fix: fan out in the adapter before validate, cap after fan-out, `dropped:{reason:'cap'|'queue-full'}` for every trim; one bucket on the socket write path in `ctl.mjs`. (REQ §9 send, A10; IMPL M1 pilot.mjs, M2 bucket.mjs)
19. **Game-over and stale decisions race `send`.** Validate has no phase check, so 15 orders land on a finished game; a decision older than ~2 s of game time is sent anyway. Fix: validate drops everything when `lifecycle !== 'active'`; abort an in-flight decision on `done`; stamp packets with the encoded clock and discard decisions older than a threshold. *Disputed:* the concurrency reviewer's "premise checks" (enemy count near target grew) are game strategy in the adapter; leave to the prompt and `lastOrders`. (REQ A9, §9 validate; IMPL M1 pilot.mjs)
20. **Prefix caching: Haiku's minimum is 4096 tokens, and the check is one-shot.** A ~1.5k prefix caches on Sonnet 5 (1024) and Opus 5 (512), never on Haiku 4.5, and padding later changes the prompt sha between compared games. Fix: pad the shared system prompt past 4096 once, up front, byte-identical across models; record the four cache fields every call and have `pace` fail the summary below 90% hit rate after call 2. The `countTokens` call as written is malformed: it needs `model` and `messages`. (REQ M3, §14; IMPL M1, M4 step 2)
21. **Token estimate is prose-calibrated; the "real" number is wrong on cold calls.** Digit-dense packets tokenize nearer chars/2.5, Sonnet 5 tokenizes ~30% heavier than 4.6, and `input_tokens` equals the packet only on a cache hit. Fix: calibrate the divisor from `countTokens` over fixtures and assert it; record packet tokens only when `cache_read_input_tokens > 0`. (REQ P2; IMPL M3 token check)
22. **Forced tool choice on every heartbeat manufactures orders.** ~200 mandatory calls per game where the right answer is often nothing; with "spend everything" prompting, the model invents moves. Fix: a required `act:boolean` or a `noop` variant so "nothing" is a one-token answer; replace the "≥ 2 orders per decision" target with orders-not-dropped. (REQ M1, §1; IMPL M1 model.mjs)

## S3 — fix before M6, or the iteration loop lies

23. **Recorder loses the tail that explains a crash and blocks the hot loop.** 4 KB buffer, 250 ms flush, sync writes on the WebSocket thread; no SIGINT/SIGTERM/uncaught handlers. Fix: async stream with backpressure for `state`; immediate write for `trigger`/`call`/`decision`/`result`/`done`; signal and error handlers flush; `pace` uses wall `t` only. (REQ R1; IMPL M1 record.mjs)
24. **Replay by nearest state cannot be byte-exact.** Coalescing and re-decides mean "nearest before" is often not the encoded snapshot. Fix: index every recorded state; the `call` line carries `{stateRef, prevRef, eventRefs, lastOrders}`. (IMPL M5 replay.mjs)
25. **Fixtures: produced by a skipped test, scrubbed by heuristic, in a public repo.** Fix: `bin/record.mjs` as a tool against local or live; allowlist scrub that keeps only fields the coder reads, renumbers ids, drops `name`/`seed`/`player`; a test that fails on any key outside the allowlist or a pattern like `ash_`, `@`, 16-hex. Open question: `CLAUDE.md` bans hosts in tracked files, but the README, `.mcp.json` and REQ §9 all carry the public play host; decide whether the rule means private hosts. (IMPL M2 tests, M3 goldens)
26. **Byte-exact goldens over an 11-layer coder that changes every game.** `--update` becomes a reflex. Fix: 2–3 readable goldens (opening, firefight, late) reviewed in diffs; property tests for the rest (layer order and priorities, integers only, vocabulary from `ABBR`, no id leakage, each visible enemy once); parameterize the 600 check on `--packet-max`. (REQ A12; IMPL M3 tests)
27. **Timing tests run on the wall clock.** Bucket, backoff, heartbeat, recorder flush. Fix: injected `{now, setTimeout, clearTimeout, setInterval}` threaded through all four; assert on virtual time. (IMPL M0 interfaces, M1, M2)
28. **Node 20.20 specifics.** `--env-file` throws when `.env` is absent (`--env-file-if-exists` is 22.9+): load env in JS or guard the script. No `--test-force-exit`: every timer `.unref()`, every test `after()` teardown, or `node --test` hangs. `node --test test/` for discovery. `parseArgs` has no `allowUnknown`; the real problem is `strict:false` parsing `--ashfall-size 200` as a boolean plus positional; write the grammar the hand parser implements. Adapter loader: validate the name against `/^[a-z0-9-]+$/`, resolve with `new URL(..., import.meta.url)`, and check `err.url` before claiming the game does not exist. (IMPL Stack, M0)
29. **The boundary test is a grep.** Catches literal imports only. Fix: walk the core import graph transitively and assert no resolved path under `src/games/`; additionally the core suite must pass with `src/games/ashfall/` renamed away. (REQ §2; IMPL M1 exit)
30. **Event ring of 200 floods under `attacked`; `seq` scope across rejoin unknown.** Fix: collapse repeats by `(kind,key)` at insert, per-class capacity so `done`/`idle` survive; ask the Ashfall dev whether `seq` is per game or per socket. (IMPL M2 ctl.mjs)
31. **Missing scope that blocks a live game.** No manual abort besides SIGINT (which item 23 makes lossy); no repeat-suppressor for a model that issues the same `build` 15 times per call; the system prompt, the biggest single lever, is one task line. Fix: a `--stop-file` or stdin `q` that flushes and leaves; a same-cmd-same-args suppressor within a decision and across the last N; a prompt section stating the packet vocabulary contract and what game 12 inherits from game 11's lessons. (IMPL M4)
32. **Cut for the first live game.** `--full-every`, concede-on-budget, most of the `pace` table (start with decisions, median reaction, tokens, result), `ranks()`/`say()`. (IMPL M1, M5)
