# Adversarial review of the built harness — 2026-09-12

**Status:** all items fixed on 2026-09-12 (91 tests, 3 skipped). Not done: pricing the 1-hour cache-write breakdown (we use 5-minute ephemeral only). The S1 transport and heartbeat fixes are covered by offline tests (`test/games/ashfall/ctl-offline.test.mjs`, `test/core/pilot.test.mjs`) and have not yet been through a live game.

Four independent Opus reviewers (security, DRY/KISS, correctness/concurrency, measurement/tests) on the M0–M6 code, after game 12. Findings merged, deduplicated, ranked by what it costs in a live game or in the truth of the numbers. Every item was reproduced by the reviewer with an offline probe or recomputed from `runs/ashfall-28.jsonl`; the top items were re-read in source before this was written. Severity: **S1** breaks a live game or corrupts the measurement; **S2** wrong by construction, cheap now; **S3** cleanup.

## S1

1. **Reconnect storm.** `ctl.mjs:73-81,103`. `reconnectLoop`'s catch calls `st.ws.terminate()` on a socket that already helloed; its `close` handler starts a *second* `reconnect()` while the first keeps iterating. Probe: failed rejoin → 21 sockets in 4 s; failed `establish` → 14 533 opens in 1.5 s. The hub's per-IP socket limit bans the account mid-game; the trigger is a revoked key or a rejoin the hub refuses. Fix: `st.reconnecting` guard in the close handler; detach handlers before terminating in the catch. Also: the loop never gives up (`:90`), `em.emit('close')` at `:80` is unreachable, `index.mjs` never forwards it, and `pilot.mjs` has no handler, so transport death hangs the run forever with the ref'd keep-alive holding the process. Cap attempts, forward `close` → `finish({outcome:{}}, 'transport')`, and time out `request()` (a socket that stays open but stops answering hangs `send` → `decide`).
2. **Heartbeat fires in `pregame`/`ended`.** `pilot.mjs:61-63` returns before `tick()`, so `st.lastCanAct` keeps its initial `true` and the heartbeat buys a real model call every 3 s while the game waits for an opponent; orders drop `stale`, `decisions` and cost inflate, `prevDecisionState` becomes a pregame snapshot. Fix: tick with `canAct:false` on non-active lifecycles.
3. **Heartbeat dies after its first suppressed fire.** `triggers.mjs:72-81`. Rescheduling only happens in `markStart`; a heartbeat resolved to `fire:null` (canAct false, cooldown, suspended) never reschedules. For any game whose `canAct` flips (the mock does) liveness is gone after the first opponent phase. Fix: reschedule inside `fireHeartbeat` when nothing fires.
4. **Prototype-chain lookups on model strings.** `validate.mjs:25,32,43`: `BUILDING_COST['constructor']` is `Object`, not `undefined`; `ore -= Object` makes the bank `NaN` and **every later cost check passes** (probe: a 300-ore core sent with 100 ore). `expand.mjs:32,49`: `ID_FIELDS['constructor']` throws before the bad-cmd check and kills the decision (and the process in rehearse). Fix: `Object.hasOwn` at all five sites, or `__proto__: null` tables.
5. **Packet headline is in the wrong currency.** REQ §1 defines the metric as real input tokens beyond the cached prefix ≤ 600. Game 12 real p50 is **660** (fails); HANDOFF and the games note quote est 481 (passes). The trimmer budgets est tokens too, so 600 est ≈ 660 real. Fix: report `packetP50` (real) as the headline; default `packetMax` ≈ 460 est, or print the ~180-token framing constant beside it.
6. **40 % of "reaction times" are not reactions.** `pilot.mjs:97` anchors on `min(tr.t)`, but heartbeat and derived triggers stamp `t = clock.now()` at tick time. 31/77 decisions are so anchored (p50 2.1 s vs 3.8 s for hub-event-anchored); 10 of the 35 reported samples. Honest event-only reaction is p50 4.04 s / p90 7.15 s, still inside target. Fix: `derived:true` on the trigger line; pace reports event-anchored only, and prints `reactionSamples` and a `timeouts` count (8 timeouts, two > 12 s, are invisible in the row today).
7. **A third of reaction time is unattributed.** `totalMs − Σ(encode,api,expand,validate,send)` p50 1 318 ms, p90 2 530 ms; `sendMs` p50 is 38 ms so it is queue, not transport. HANDOFF says only `totalMs` and `apiMs` exist; four more fields are recorded and ignored. The one change that makes M7 steps 3 and 4 measurable: stamp `tickT` and `markStartT` on the call line so reaction splits arrival→tick→start→send.

## S2

8. **`--full-every` is parsed, recorded, and discarded.** `bin/pilot.mjs:59` and `bin/replay.mjs:20` hardcode `fullEvery: 0`. A run with `--full-every 3` records a config it did not use. Also `packet.mjs:15` uses `n % fullEvery` with `n` from 1, so decision 1 gets the slim packet. Fix: pass `cfg.fullEvery`; `(n − 1) % fullEvery`.
9. **Rehearsal runs a different pipeline than the pilot.** `bin/rehearse.mjs:50-54` re-implements `pilot.mjs:121-136` and has drifted: every kept cmd marked `ok:true`, `expand` called without `recent` so `repeat` drops can't fire, its own cap/validate order, its own `createModel` call with a 20 s deadline. M4's "16/16 legal" was measured on code that does not play. Fix: export `applyOrders({adapter, orders, state, orderCap})` from pilot and call it from both; one `bin/_boot.mjs` for `ROOT`/`loadEnv`/`parseArgs`/prices/`createModel` (three bins repeat it).
10. **`Promise.all` in send misreports partial batches.** `index.mjs:223`: one `disconnected` throw rejects all, and `pilot.mjs:133` rewrites every cmd's result to transport failure including ones the hub executed. Fix: `allSettled`, per-cmd results.
11. **Heartbeat aligns the interval, not the instant.** `triggers.mjs:8,76`: fire lands at `markStart + 3000`, up to `refreshMs` after the last state push, so the packet is built from a stale snapshot. The alignment test passes only because `markStart` is at t = 0. Fix: `ceil((now + hb) / refresh) * refresh − now`.
12. **Heartbeat before the first state crashes the decision.** `pilot.mjs:96` `ensureState(null)` throws. Fix: `if (!latest) break` after `markStart`.
13. **Cache never paid for in game 12.** All 85 calls read 8 384 cached tokens and wrote 0; the prefix came from the game-27 smoke run. `$0.32` excludes the ~$0.02 write a new prompt or schema pays, and the ≥ 90 % hit gate cannot fail on a warm run. Fix: print `cacheWriteTokens` in the row. Also `after2 = n > 2` should be `n > 1`.
14. **Silent $0 cost.** `model.mjs:23` returns 0 when the model has no price; nothing loads `config/prices.json` in tests. Fix: warn in `createModel` when `prices[model]` is missing.
15. **Unvalidated hub frames crash the process.** `ctl.mjs:69-70`: `{"type":"event"}` or `{"type":"state"}` without a body → uncaught → exit 70. Fix: shape-check `m.ev`/`m.state`; set `maxPayload` (default is 100 MiB).
16. **Key in a flag is written to the run file.** `bin/pilot.mjs:40,47` record and print `gameOpts` including `--ashfall-key`. Env-sourced keys are not recorded. Fix: redact `/key|token|secret/i` before `config` and stderr.
17. **Run-file path from a server-supplied id.** `bin/pilot.mjs:46`, `bin/record.mjs:36`: `gameId` is never sanitised; `../` escapes `runs/`. Fix: `replace(/[^A-Za-z0-9_-]/g, '_')`.
18. **`fs.writeSync` not looped.** `record.mjs:162`: a short write truncates a line while every later ref still counts it. Fix: loop on bytes written.
19. **Self-healing tests.** `coder.test.mjs:23` writes the golden if missing then asserts equality (vacuous on a fresh checkout). `calibration.test.mjs:24-29` overwrites `calibration.json` when a key is present, returns silently without one, and asserts `1 < divisor < 6`. Fix: drop the `existsSync` branch; write `.new` and assert ±10 % of the committed 1.34. Also `src/games/ashfall/index.mjs:14` reads a divisor out of `test/`: move `calibration.json` under `src/games/ashfall/`.
20. **M7 plan confounds.** Step 2 bundles three variables (thinking off also removes `output_config`; dropping `note` changes the schema sha → grammar recompile + cache write; cap 15→8). Split into three games. Step 6's stopping rule cannot move: 80 of 97 drops are `noore`, a property of the frozen prompt, not the packet; use real-token p50 and no-op share. Both proposed metrics need no new instrumentation: `replayDecision` already returns per-layer text (the `fields` layer is ~150 of 536 est tokens and constant every packet), and `call.packet` is recorded in full: **median 70 % of a packet's lines are identical to the previous packet**. That is the novelty number, computable on game 12 today.

## S3

- Replay proves encode determinism against the recorded packet, not that the API saw it; 85/85 hold (HANDOFF says 77/77, which excludes the 8 skipped calls). Say so.
- `ctl.mjs:43-48` takes a bucket token before checking the socket: past ~50 queued frames a cmd can go out on the new socket after `failPending` already marked it `disconnected` (ghost order). Capture a socket epoch in `request()`.
- Bucket does not cover the WS upgrade (REQ §9 says every frame); that is what makes item 1 unbounded.
- SIGINT: `bin/pilot.mjs:48` closes the recorder while `runPilot` still writes, and `adapter.leave()` has no timeout. Call `finish()` and race `leave` against 2 s.
- `model.mjs:48` only call 1 gets the 3× deadline though calls 1 and 2 timed out cold; extend until the first response with `cache_read_input_tokens > 0`. A pilot abort and a real deadline both record `stop:'timeout'`.
- Events buffered before a disconnect keep their pre-outage `t0`, so the first post-reconnect decision's reaction includes the outage; dirty triggers left by a budget-stop resurface with stale `t`.
- Recorder 4 MB backpressure is dead: flush at 64 KB means `droppedStates` is always 0. Delete it.
- `sig` in `expand.mjs:12` uses the key array as a `JSON.stringify` replacer, which applies at every depth; a nested arg (`near{x,z,r}`) would collide as `repeat`.
- Dead code (~13 lines, zero callers): `ctl` `peekEvents`/`ranks`/`say`/`state`, `record` `droppedStates`/public `flush`, mock `results`, `args` `positional`, `replay` `base`, `clock.pending`, `nullModel({clock})`. `types.mjs` (29 lines) is imported by nothing and duplicates REQ §4.
- Knobs with no non-test caller: ctl `rate`/`burst`/`WS`/`helloTimeoutMs`, record `flushMs`/`maxBuffer`/`sampled`, digest `top`/`key`, cluster `typeOf`. Inline or delete (~12 lines).
- Duplicates: `readRun` in pace, replay and two tests; `events.mjs` `BUILDINGS` vs `rules.isBuilding`; `expand.mjs` `CODE` hand-typed inverse of `abbr.UNIT`; `Math.hypot` in coder and expand vs `cluster.dist`; `scrub.test.mjs` re-declares `helpers` fixture loaders. `pace.mjs:21,39` is O(n²) over decisions.
- `decide()` is 71 lines; item 9's `applyOrders` extraction brings it to ~45.
- Untested: `args.mjs`, `lib/cluster.mjs`, `rules.mjs`, `opening.mjs`, rehearse scoring, pace/replay exit codes (the `ok` gate is never asserted to fail). `ctl.test.mjs` is entirely local-hub-gated, so items 1, 10, 15 and the ghost order have no offline coverage; every pilot test sets `heartbeatMs: 100000`, which is why items 2, 3, 12 are invisible.
