Four Opus reviewers, one per area (core loop, Ashfall adapter, measurement tools, prompt/tests/docs), on the tree with the game32 prompt, `--ashfall-search-fields` and `bin/campaign.mjs` uncommitted. CONFIRMED = reproduced by a probe; PLAUSIBLE = read from code. Nothing fixed yet.

## S1 — wrong results or wrong measurements

1. **`--stream` skips the sticky repeat guard** (CONFIRMED, core + adapter). `src/core/pilot.mjs:197` closes every streamed decision with `adapter.send([], {partial:false})`, no-ops included; `src/games/ashfall/index.mjs:97` pushes a `recent` entry per send, so two no-ops evict the window and a repeated `b ba` / `rs ar w` goes out and is paid twice. Non-stream runs never hit it. Fix: skip the close (or the push) when nothing was sent.
2. **`--stream`: orders already on the wire recorded as a skipped call** (CONFIRMED). `pilot.mjs:169` the `finished` guard sits above the partial-decision branch: a chunk sent, then `done`/stop/budget, then the call returns → `call{skipped:'ended'}`, no `decision`/`result` rows; `lastOrders` stale, every tool undercounts. Fix: move the guard below the partial branch.
3. **Recorder appends but restarts the line counter** (CONFIRMED). `src/core/record.mjs:18-36`: a second run on the same gameId (campaign resume, rejoin) writes refs offset by the old line count; replay throws or replays the wrong state. Fix: seed `lines` from the file, or open `wx` and suffix.
4. **Bench gate `pushTarget` now passes the defect it exists to catch** (CONFIRMED). `test/games/ashfall/bench/rules.mjs`: `towardEnemy <=` plus `{0,0}` in goals. Re-scored: game 33 (43 × `am 0,0`) 0/23 → 55/63. `cases.mjs` `push` likewise accepts `am army 0,0`. Fix: drop the centre goal, require the push within 15 of a building/mirror/far field.
5. **`search`/`search2` cases don't test the waypoint** (CONFIRMED). They pass any far unexplored field within 15 (5 of 13 in the fixture), so "10/10" measures "went somewhere far", not "followed M". Fix: score against `searchField(s)`.
6. **Campaign A/B metric miscalibrated** (CONFIRMED). `bin/campaign.mjs highClassWait`: with `--event-tick` the push wait is ~0, so any `waitMs > 0` is time behind a call in flight; the 600 ms cut hides 25–35 points (games 53–56: 40/51/49/38% reported vs 65/85/75/69% true) and the reserve's claimed effect lives below it. Also counts derived triggers (waitMs ≈ 0 by construction). Fix: `behindMs = 0` under event tick, filter `derived`.
7. **Search has no terminal fallback** (CONFIRMED). `coder.mjs searchField` → null when every field is explored (the normal end of a search), when `myBase` is missing, or when the ball is raiders/wardens; M prints `none` and rule 3 has no legal target: the game-33 stall by another route. Fix: emit the mirror when the list is empty; count any combat unit.
8. **Prompt contradictions** (`prompts/ashfall/game32-sonnet.md`). Rule 3's untouched tail still says "never send the ball to a field"; the M description carries the literal `search f5@78,13` (HANDOFF's "no coordinate at all" is false); "an `enemy` field in `F`" is unreadable because the fold strips the kind; "only coordinates on this packet" contradicts rule 2's turret placement and `b tu 62,-4`. Fix each line.
9. **Search waypoint can be a crystal pocket** (CONFIRMED). `coder.mjs` never filters `res === 'crystal'`; `f13c@…` ranks 4th in the fixture, and the rules text says crystal is never near a base. Fix: filter crystal.

## S2

10. `--overlap 2 --stream` share one `open` flag (`index.mjs:42,97`): interleaved streams merge signatures across decisions and a dead stream leaves `open` true. Fix: key `recent`/`open` per decision.
11. `--reserve` accepts unknown class names silently (`triggers.mjs:19,38`): a typo runs `--overlap 2` as 1 all game. Fix: validate against `classes`.
12. Pregame events are never drained (`pilot.mjs:79-83`): the first decision's `eventArrivalT` predates the start, inflating reaction p90. Fix: clear `eventsSince` in the non-active branch.
13. Campaign resume assumes contiguous indexes (`campaign.mjs:191-198`): an exit-1 game (outcome `{}`) is skipped and a finished one overwritten; `--ab` on resume comes from argv while `base` comes from the state file. Fix: iterate `i` over `0..n` and take `state.ab`.

15. Trajectory's arm skips `stale`/`prior` (`trajectory.mjs:246`) so it is scored under a laxer pipeline than the recorded column. Fix: pass `decidedOn`, `staleAfterMs`, `prior`.
16. `classes.mjs` reaction mixes tick-anchored and event-anchored clocks; `pace` filters these. Fix: reuse pace's filter.
17. Statistics: the report medians per-game `behindPct` unweighted (pool calls instead); Wilson at n=10 is ±26 points, so overlapping intervals cannot decide the A/B. State the wait share as the decision metric and win rate as the guard.
18. Train queue cap not threaded across stream chunks (`expand.mjs:74-84`): 6 sent where 5 fit. Stale-seat cleanup (`index.mjs:74-79`) has no try/catch and `ctl.request` rejects on disconnect → `seat()` throws, run dies.
